### 悟道判定

- 翻牌堆顶一张**即时判定**（不进判定区）
- **花色 ↔ 五行**：♠水 ♥火 ♣木 ♦金
- **灵根修正**：单灵根命中花色则**结果翻转**（期望 ≈75%）；双灵根命中且成功则修为 +1；三灵根及以上失败时**心魔反噬**弃 1 张手牌

## 六、伤害链

```
法宝合计 −1（护身＋秘宝不叠加） → 被动减伤 → **平减保底 1 伤** → 道心抵挡（每回合限 1 次） → 伴兽替主承伤 → 本体扣寿元 → 濒死
```

伴兽承伤**只插在 `applyDamage()` 唯一位置**，不得在濒死结算中重复承伤。

**道心抵挡**：2 点道心抵 1 点伤害，**每回合限 1 次**；**濒死自救**时 1 点道心即可稳住心神（寿元回复至 1）；部分主动技以道心为发动消耗。
**平减保底**：法宝与被动减伤合计不得把伤害压到 0，普通神通至少造成 1 点（仅道心可完全抵挡）。

## 七、术语禁用清单

以下词**严禁**出现在代码、UI 与文档中（完整对照见 [游戏机制.md 第九节](./游戏机制.md)）：

| 禁用词 | 状态 | 替换 |
|---|---|---|
| 星魂契约 | docs 全库 0 命中，新造 | **灵魂契约** |
| 劫修 | docs 全库 0 命中，新造 | **邪修** |
| 气血 | 仅 raw 少量，md 无 | **寿元** |
| 灵识 | 仅 raw 少量，md 无 | **道心** |
| 灵酒 | 仅 raw 少量，md 无 | **灵药** |
| 符箓 | 全库仅 2 文件，非主流 | **符篆** |
| 杀／闪／桃／酒／锦囊／体力 | 三国杀术语 | 见第一节对照表 |

**原则**：以 `docs/md/` 设定库为唯一权威口径；`docs/raw/` 仅在 md 无对应词时补充并标注来源。任何新术语必须先检索 docs 取得出处，检索不到即视为臆造、禁用。
