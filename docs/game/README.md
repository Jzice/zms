# 掌门杀 · 修真门派掌门路

一款运行在浏览器中的**修真主题身份竞技卡牌游戏**，玩法机制对标《三国杀》，世界观、角色、技能、法宝、灵根、本命、势力、地域、灵地、契约**全部取自** `docs/` 中《修真门派掌门路》设定资料，**术语严禁新造**。

架构与 UI 对标 `learn_kill`（学堂杀）工程，构建为**单 HTML 文件**（双击即玩、支持 PeerJS 联机）。

---

## 快速开始

```bash
npm install        # 首次安装依赖
npm run dev        # 开发服务器（HMR）
npm run build      # 构建两种模式到 dist/
```

无需服务器，直接打开构建产物即可游玩：

| 产物 | PeerJS 方式 | 适用场景 |
|---|---|---|
| `dist/掌门杀.html` | CDN script 标签 | 体积最小（约 174 KB），需联网联机 |
| `dist/掌门杀.bundled.html` | 内嵌 peerjs 包 | 完全自包含（约 260 KB），联机可离线 |

## 核心玩法速览

- **四方身份**：正道（掌门／弟子／长老／客卿／执事）、外道（邪修／鬼修／魔修／兽类）、隐匿（散修／黑手／公正鬼）、公开高位（座主／老祖／镇守／界主／城主）；**人数自适应配比**
- **116 名角色**：人类 91（含散修姜炎）、兽类 14、魔修 7、鬼修 4；血魔井改为法宝道具；覆盖练气→化神五境二十层
- **双轴博弈**：阵营（人类／兽类／魔修／鬼修）决定联合关系，身份决定个人胜利条件
- **灵魂契约**：以真名录于羊皮纸，凉风扫过而成立，心头锁为记；背盟遭灵魂反噬（公正鬼监督时加重）
- **境界成长**：练气→筑基→金丹→元婴→化神，每境四阶共 20 层；悟道／闭关／感悟三条修为途径
- **灵地门槛**：跨境突破须满足灵地阶位（筑基一阶／金丹三阶／元婴五阶／化神七阶）
- **悟道判定**：【悟道】卡翻判定牌，红色「道心澄明」、黑色「心魔滋生」，灵根纯度修正成败
- **伴兽**：御兽门修士须携伴兽同行，伴兽替主承伤，溃散则失效
- **AI 双机制（启发式 + 大模型）**：默认启发式博弈 AI；可在「🤖 大模型设置」中接入 OpenAI 兼容大模型（DeepSeek / 通义 / 智谱 / Ollama 本地等），由大模型接管全部或指定 AI 座位。大模型过慢/失败自动回退启发式，零死锁
- **主题与响应式**：顶栏 🎨 切换光线模式（白昼／夜幕／黄昏）× 仙侠配色（玉青／鎏金／黛蓝／紫宸／赤焰／雪松）；对局时**大屏椭圆牌桌、小屏列表**双形态自适应

## 术语原则

以 `docs/md/` 设定库为**唯一权威口径**；`docs/raw/` 仅在 md 无对应词时补充并标注来源。
任何新术语必须先检索 docs 取得出处，**检索不到即视为臆造、禁用**。

已禁用的臆造词示例：星魂契约（→灵魂契约）、劫修（→邪修）、迷魂阵（→乌茎泽兰八卦迷阵）、气血（→寿元）、灵识（→道心）、灵酒（→灵药）、遁光（→飞梭／遁术）、符箓（→符篆）、进阶（→境界突破）。

完整对照表见 [游戏机制.md · 术语禁用清单](./游戏机制.md#九术语禁用清单)。
