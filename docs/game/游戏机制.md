设定出处：`docs/md/设定/灵魂契约.md`（专章）、`docs/md/设定/上八门.md`、`docs/md/角色/鬼修/公正鬼.md`

|---|---|---|
| 性质 | 本界**天地法则级**契约体系；连元婴修士亦受约束（第247章） | 全场生效，无豁免 |
| 监督者 | **公正鬼**（自称「公正之鬼」，别称契约鬼） | 在场时背盟反噬加重、可看破隐匿 |
| 载体 | 「各自呈上**羊皮纸**，立灵魂契约」 | 契约卡为羊皮纸质感 |
| 凭证 | 「留下**真名**后掷还」 | 立约须留真名 → **暴露阵营/势力信息** |
| 生效感应 | 「灵魂中可感应到『**凉风扫过**』的感觉，由此确认契约生效」 | 成立时播放凉风扫过动效 |

| 违约 | 「违约时…鬼影浮现…**灵魂反噬**…当场取命，无法抵抗」（第259章） | 背盟触发灵魂反噬 |
| 形态 | 「**印堂**之上，一个**尖头鬼影**隐隐浮现」 | 尖头鬼影自头像上方（印堂）浮现 |

### 玩法形态（两者都要）

1. **【灵魂契约】卡牌**（牌堆 4 张）：出牌阶段指定他人立约；条款数据驱动（互不攻伐／共享摸牌／共享灵力／守望相助）；带期限
2. **结盟契约化**：原「结盟」迁移为灵魂契约流程，不保留两套并行机制

### ⚠ 平衡标定（唯一对 docs 的偏离）

docs 明确反噬「**当场取命，无法抵抗**」。若照搬，契约不可背叛、博弈性消失。故：

- `SOUL_BACKLASH_LETHAL = false`（默认）：背盟造成**重创**——道心清零 + 弃 2 张手牌 + 寿元损失
- **公正鬼在场时**升格为**致命**（忠实其监督者职能，赋予威慑力）

该常量位于 `src/data/contracts.ts`，为关键平衡旋钮，可随时调回。

## 三、境界成长

设定出处：`docs/md/设定/修行体系.md`

- 五境：**练气（寿 120）→ 筑基（寿 200）→ 金丹（寿 500）→ 元婴（寿 2000）→ 化神（寿约万载）**
- 每境 **初期（1-3 层）/ 中期（4-7 层）/ 后期（8-10 层）/ 大圆满（10 层）** → 共 **20 层**

### 修为三途径

| 途径 | 方式 | 收益 |
|---|---|---|
| **悟道**（主） | 打出【悟道】卡 → 翻判定牌 | 成功 修为 +4、道心 +1、展示诗词感悟；失败 修为 +1 |
| **闭关** | 回合末弃置全部手牌 | 修为 +3；本回合受伤则 −1（走火入魔被打断） |
| **感悟** | 濒死被救 / 服用灵丹 / 整回合未受伤 / 本命天赋发动 | 各 +1 |

### 灵根纯度修正

docs/md/设定/本命.md：「本命越多、灵根越杂，吸纳灵气越慢」

| 灵根 | 修正 |
|---|---|
| 单灵根 | +2 |
| 双灵根 | 0 |
| 三灵根及以上 | −1，且悟道失败时弃 1 张手牌（**心魔反噬**） |

### 悟道判定

- 翻牌堆顶一张**即时判定**（复用判定原语，不进判定区）
- 红色（♥♦）→「**道心澄明**」成功；黑色（♠♣）→「**心魔滋生**」失败（基线 50%）
- 花色↔五行：**♠水 ♥火 ♣木 ♦金**
- 灵根修正：单灵根命中花色则**结果翻转**（期望 ≈75%）；双灵根命中且成功则修为 +1

### 境界突破（**双前置条件**）

1. **修为阈值**：达到当前层所需修为
2. **灵地阶位门槛**（docs：「进阶必须一阶/三阶/五阶/七阶灵地」）：
   - 练气→筑基 需 **一阶**；筑基→金丹 需 **三阶**；金丹→元婴 需 **五阶**；元婴→化神 需 **七阶**
   - **仅跨境突破**需要灵地；阶内突破无需

突破收益（集中在 `breakthroughRealm()`）：
- **灵力上限 +1**（丹田灵力池扩大）
- 开启**本命天赋**（如齐休【料敌机先】）
- 展示**诗词感悟**（宣纸卷轴弹层）
- ⚠ **血量（寿元上限）固定，不随突破增长**——对齐三国杀「体力固定」内核；早期版本跨境 +1 上限会把单局拉长到 20+ 回合，现已取消

### 灵力与道心

| 资源 | 来源 | 用途 |
|---|---|---|
| **灵力** | 由境界派生、回合回复（+2，本域势力 +1） | 施法、悟道 |
| **道心** | **仅**由悟道判定成功产出 | 抵伤（2 抵 1，**每回合限 1 次**）、濒死自救（1 点稳住心神）、部分主动技的发动消耗 |

## 七、回合流程

```
判定（天劫 / 七星定身阵） → 摸牌 2 → 出牌 → 弃牌（上限 = 寿元） → 回合末「闭关」
```

出牌阶段可做：使用【悟道】、发动主动技／本命天赋、使用法宝、占据灵地、打出符篆／阵法／秘术、立灵魂契约、使用神通攻击。
**神通每回合限 1 张**（对齐三国杀「每回合限一张【杀】」，`SHENGTONG_PER_TURN = 1`）：防止一回合多牌斩杀，是控制单局节奏的关键旋钮。

## 八、结算优先级

1. **公开高位方**：守灵地最多者 / 本势力存活最多者
2. **掌门肃清**：外道与隐匿皆灭且掌门存活 → 掌门 + 存活护掌门方
3. **外道弑掌门**：掌门陨落 → 存活外道胜
4. **隐匿独胜**：仅剩一人且为隐匿方
5. **公正鬼**：终局存活且契约未被背盟破坏
6. **回合耗尽**：掌门尚存 → 正道守成；否则外道得势

阵营功勋：存活最多的阵营，叠加于个人胜负之上。

|---|---|---|
| **大屏**（>768px） | **牌桌模式**：椭圆牌桌（青绿径向渐变 + 内描边），牌堆／出牌区／弃牌居中悬浮 | 座位沿椭圆环**绝对定位**（`left/top` 内联坐标，0 号座位在底部中央），宽度固定 110px |
| **小屏**（≤768px） | **列表方式**：座位回归紧凑网格，卡牌横向滚动 | 座位**静态流式**排列 |

实现要点：

- `src/ui/playzone.ts` 的 `seatHtml()` **始终**写入内联 `left/top` 坐标（大屏生效）
- `src/style.css` 在 ≤768px 媒体查询中以 `!important` 覆盖：`position:static !important; transform:none !important; left:auto !important; top:auto !important`
- 二者是**配套**的：去掉 `!important` 会让窄屏内联坐标生效导致座位错位；去掉内联坐标会让大屏牌桌塌陷
- `npm run smoke:ui` 断言两种形态的 `computed position`（大屏 `absolute` / 小屏 `static`）

### AI 双机制（启发式 + 大模型接管）

| 维度 | 启发式 AI | 大模型接管 |
|---|---|---|
| 决策入口 | `ai.ts` 的 `enumerateActions()` 枚举合法动作 → `executeAction()` 执行 | `llm/agent.ts` 将动作枚举转为候选项交由模型选择 |
| 目标选取 | `aibrain.ts` 信念推断（依「谁攻击谁」观察推断身份方概率）→ 博弈式目标评分 | Prompt 携带信念摘要，由模型推理 |
| 触发条件 | 默认路径 | `p.aiMode === 'llm'` 且 `llmReady()` 为真（配置有效且已开启该席位） |
| 失败兜底 | —— | 超时 / 异常 / 输出非法 → **自动回退启发式**；坏决策累计达阈值 `demoteLlmSeat` 本局降级 |
| 适用场景 | 单机、联机（房主侧） | 单机、联机（房主侧）；联机客人只读，随 `state_sync` 同步 `aiMode` |

**零死锁**是硬性要求：大模型不可用或异常时，对局必须继续推进，不得因等待模型而卡死。

### 主题

`body[data-mode]`（白昼／夜幕／黄昏）× `body[data-theme]`（玉青／鎏金／黛蓝／紫宸／赤焰／雪松），全部色彩由 CSS 变量驱动；选择持久化于本地档案，首帧内联脚本兜底避免闪烁。主题只影响呈现，**不影响任何结算逻辑**。
