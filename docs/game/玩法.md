# 掌门杀 · 玩法指南

面向玩家的上手说明。规则细节与设定出处见 [游戏机制.md](./游戏机制.md)，卡牌清单见 [卡牌.md](./卡牌.md)。

> 所有术语（神通、护身、灵丹、悟道、灵魂契约、灵地、寿元、道心……）均取自《修真门派掌门路》设定库。

---

## 一、一分钟上手

1. **开局**：大厅选择阵营／地域筛选 → 勾选角色 → 设定人数（4–10）→ 「开始游戏」
2. **你的回合**亮起金色光圈后：摸牌 → 出牌 → 弃牌 → 回合末「闭关」
3. **出牌**：点击手牌 → 选择目标（点击座位）→ 确认
4. **目标**：点击他人座位即选中；再次点击取消
5. **胜利**：按身份目标判定，见 [第五节](#五身份与胜负判定)

---

## 二、开局设置

| 项 | 说明 |
|---|---|
| **人数** | 4–10 人；不足时由 **AI** 补齐空位 |
| **阵营筛选** | 人类／兽类／魔修／鬼修，用于快速挑选同阵营角色 |
| **地域筛选** | 白山／南疆／外海／齐云／跨区／跨界 |
| **势力层级** | 超级宗门 → 宗门 → 家族 → 附庸，决定角色的归属与加成 |
| **角色** | 116 名可选，含御兽门角色（须选一**伴兽**） |
| **身份** | 房主按**方**勾选参与的身份，系统按人数自动配比 |
| **联机** | 「创建房间」得 6 位房号，他人输入房号加入；掉线者自动转 AI |

**阵营与身份是两回事**：

- **阵营**（公开，来自角色）：人类／兽类／魔修／鬼修 —— 决定**联合亲和**，同阵营可结盟
- **身份**（多隐藏）：决定**个人胜利条件**

## 三、对局界面

### 大屏：牌桌模式

```
        （座位沿椭圆环绕，0 号本座在正下方）
     ┌──────────────────────────────┐
     │   座位        座位           │
     │      ┌────────────────┐      │
     │ 座位 │ 牌堆 出牌区 弃牌 │ 座位 │
     │      └────────────────┘      │
     │   座位        座位           │
     └──────────────────────────────┘
```

- **椭圆牌桌**：中心为牌堆、出牌区（最近打出的牌）与弃牌堆
- **座位卡**：头像、姓名、角色名与势力、寿元、境界与修为进度、灵力／道心／灵地阶位、阵营、身份、法宝四槽、伴兽徽标、手牌数
- **金色光圈**：当前行动者；**💭 气泡**：大模型正在思考
- **🔒 心头锁**：已立灵魂契约

### 小屏：列表方式

屏幕宽度 ≤768px 时自动折叠为**座位网格列表**，牌桌背景收起，卡牌区横向滚动。功能完全一致，仅呈现形式不同。

### 侧栏

- **战报**：逐条记录伤害、判定、契约、突破、离场等事件
- **聊天室**：与同场玩家对话

## 四、回合流程

```
判定（天劫 / 七星定身阵） → 摸牌 2 → 出牌 → 弃牌（上限 = 寿元） → 回合末「闭关」
```

| 阶段 | 内容 |
|---|---|
| **判定** | 场上有延时类判定牌时逐个结算（【天劫】【七星定身阵】） |
| **摸牌** | 摸 2 张；部分角色有「摸牌阶段多摸 1 张」类天赋 |
| **出牌** | 见下节，次数与顺序自由安排 |
| **弃牌** | 手牌上限 = 当前**寿元**（秘宝 +1、被动修正另计），超出须弃至上限 |
| **回合末** | 可「闭关」：弃置全部手牌换修为；若本回合受伤则收益减 1（走火入魔被打断） |

### 出牌阶段可以做什么

- 打出**神通**攻击（需在攻击范围内）
- 打出**护身**抵挡【十方风火归元大阵】等群体效果
- 打出**悟道**卡翻判定牌，**修为 +4、道心 +1**（成功）
- 发动**主动技**／**本命天赋**（多数有灵力或手牌消耗）
- 使用**法宝**（四槽：本命法宝·法器 / 护身 / 飞梭·灵舟 / 秘宝·重宝）
- 打出**符篆／阵法／秘术**（含【灵魂契约】）
- **占据灵地**（提供灵地阶位，是跨境突破的门槛条件）

### 资源速查

| 资源 | 来源 | 用途 |
|---|---|---|
| **寿元** | 境界决定上限，受伤扣减 | 手牌上限；归零则濒死 |
| **灵力** | 境界派生，回合回复 +2（本域势力 +1）；灵药 +1 | 发动法术、悟道 |
| **道心** | **仅**由悟道判定成功产出 | 抵伤（2 抵 1）、濒死自救（1 点稳住心神）、部分主动技的发动消耗 |
| **修为** | 悟道 / 闭关 / 感悟 | 境界突破 |

## 五、身份与胜负判定

| 身份 | 公开性 | 目标 |
|---|---|---|
| **掌门** | 公开 | 肃清全部外道与隐匿方，且自身存活 |
| **弟子／长老／客卿／执事** | 隐藏 | 护掌门，正道胜则胜 |
| **邪修／鬼修／魔修／兽类** | 隐藏 | 弑掌门夺权 |
| **散修** | 隐藏 | 独善其身，存活至终局 |
| **黑手** | 隐藏 | 隐匿到最后与掌门单挑独胜 |
| **公正鬼** | 隐藏 | 终局存活且灵魂契约未被背盟破坏 |
| **座主／老祖／界主** | 公开 | 势力称雄 / 维持秩序 |
| **镇守／城主** | 公开 | 守灵地至终局 / 终局占据灵地最多 |

**结算优先级**：公开高位方 → 掌门肃清 → 外道弑掌门 → 隐匿独胜 → 公正鬼 → 回合耗尽。
阵营功勋叠加于个人胜负之上。

## 六、灵魂契约

出牌阶段打出【灵魂契约】（牌堆共 4 张），指定一名其他角色立约：

1. **留真名**——立约须报真名，等于**暴露自己的阵营与势力**
2. **凉风扫过**——契约成立的感应动效
3. **心头锁**——双方座位显示 🔒 印记，提示束缚关系
4. **条款**由数据驱动：互不攻伐 / 共享摸牌 / 共享灵力 / 守望相助，可带期限

**背盟反噬**：违背条款将遭灵魂反噬（道心清零 + 弃 2 张手牌 + 寿元损失）。
**公正鬼**在场时反噬升格为致命——它是契约的监督者。

> 若对方正在与你交战，先考虑契约条款是否利己：**互不攻伐**能保命，但会失去主动进攻机会。

## 七、境界成长

- **五境二十层**：练气（寿 120）→ 筑基（200）→ 金丹（500）→ 元婴（2000）→ 化神（万载），每境分初期／中期／后期／大圆满
- **悟道**：翻判定牌，红色「道心澄明」成功（修为 +4、道心 +1），黑色「心魔滋生」失败（修为 +1）
- **灵根修正**：单灵根 +2；双灵根 0；三灵根及以上 −1，且失败时**心魔反噬**弃 1 张手牌
- **闭关**：回合末弃光手牌换修为 +3
- **感悟**：濒死被救 / 服用灵丹 / 整回合未受伤 / 本命天赋发动，各 +1
- **跨境突破双前置**：修为阈值 **且** 灵地阶位（筑基 1 阶 / 金丹 3 阶 / 元婴 5 阶 / 化神 7 阶）
- **突破收益**：寿元上限 +1、灵力上限 +1、开启**本命天赋**、展示诗词感悟

## 八、AI 与大模型接管

- **默认**：启发式 AI。会依据「谁攻击了谁」推断各玩家身份方概率，据此选择目标与行动
- **大模型接管**：顶栏 🤖 打开设置，填写服务商（DeepSeek / 通义 / 智谱 / Ollama 本地 / 自定义）与 Base URL、API Key、模型名，可**全部接管**或**指定席位接管**
- **兜底**：模型超时、报错或输出非法动作时**自动回退启发式**，对局不会卡死；反复出错则该席位本局降级
- **提示**：大模型只看到公开信息与你的手牌，**不会**看到他人手牌与未揭示的身份

## 九、主题与个性化

顶栏 🎨 打开主题面板：

- **光线**：白昼（暖纸）／夜幕（默认墨绿）／黄昏（绛紫）
- **配色**：玉青（默认）／鎏金／黛蓝／紫宸／赤焰／雪松

选择会记入本地档案，下次打开自动恢复。主题只影响呈现，**不影响任何结算**。

## 十、联机

1. 房主「创建房间」→ 得到 **6 位房号**
2. 他人输入房号加入
3. 房主设定人数与身份后开局
4. **房主权威**：房主运行游戏循环并广播牌局快照；其他端为只读 + 出牌选择上传
5. 有人掉线／退出 → 该席位自动转 AI，对局继续

## 十一、常见问题

| 问题 | 解答 |
|---|---|
| 为什么手牌上限这么高？ | 手牌上限 = **寿元**，境界越高上限越高；超出须在弃牌阶段弃置 |
| 打出【悟道】有什么风险？ | 判定失败仅修为 +1；但**三灵根及以上**会触发心魔反噬，额外弃 1 张手牌 |
| 灵力不够用？ | 灵力由境界派生、回合回复 +2；发动高阶技需攒灵力，或靠本域势力加 +1 |
| 怎么赢得快？ | 掌门需**肃清**外道与隐匿，不能只打外道；留意黑手可能一路隐匿到终局 |
| 契约反噬能避免吗？ | 履约即可 |
| 手机能玩吗？ | 能。窄屏自动切换为列表布局，顶栏折叠、手牌横向滚动 |
| 大模型一直不响应？ | 检查 Base URL 与 API Key 是否可用；未配置时默认使用启发式 AI，不影响开局 |
